# Manga Downloader

أداة بايثون بسيطة ومرنة لتحميل فصول المانغا من المواقع التي تعرضها على شكل صور، ثم تحويل كل فصل إلى ملف PDF واحد.

---

## ✨ المميزات
- تحميل صور الفصل بالتتابع (صورة تلو الأخرى).
- تحويل جميع صور الفصل إلى ملف PDF واحد.
- دعم الانتقال التلقائي إلى الفصل التالي باستخدام محدد CSS قابل للتخصيص.
- تقليل احتمالية كشف الأتمتة باستخدام:
  - Selenium
  - webdriver-manager
  - selenium-stealth

---

## 🧰 المتطلبات
- Python 3.8 أو أحدث
- Google Chrome مثبت على النظام
- الحزم التالية (أو استخدم `requirements.txt`):
  - selenium
  - webdriver-manager
  - selenium-stealth
  - pillow

---

## ⚙️ التثبيت

### 1️⃣ إنشاء وتفعيل بيئة افتراضية (Windows)
```bash
python -m venv venv
venv\Scripts\activate
````

### 2️⃣ تثبيت الحزم
```bash
pip install -r requirements.txt
```
 
او

```bash
pip install selenium webdriver-manager selenium-stealth pillow
```

## ▶️ الاستخدام

1. افتح مجلد المشروع.
2. شغّل البرنامج:

```bash
python main.py
```

3. أدخل البيانات المطلوبة عند الطلب:

   * رابط الفصل الأول
   * عدد الفصول المراد تحميلها
   * محدد CSS لزر **الفصل التالي**
     (الافتراضي: `a#next-chapter`)
   * بادئة روابط الصور
     (مثال: `https://site.com/uploads`)
4. سيتم فتح المتصفح تلقائيًا.
   في حال ظهور Cloudflare، أكمل التحقق يدويًا كما هو موضح داخل البرنامج.
5. سيتم:

   * حفظ الصور داخل مجلدات باسم `chapter_<number>`
   * إنشاء ملف PDF باسم `chapter_<number>.pdf`

---

## ⚠️ ملاحظات مهمة

* تأكد من أن استخدام الأداة لا ينتهك شروط الموقع أو حقوق النشر.
* في حال عدم تحميل الصور:

  * تحقق من `image_url_prefix`
  * أو حدّث محدد CSS للفصل التالي.
* بعض المواقع تستخدم حماية قوية ضد الأتمتة، وقد يتطلب ذلك تعديلات إضافية أو حلول متقدمة.

## 📁 هيكل المشروع

* `main.py` — نقطة التشغيل الرئيسية.
* `start_driver.py` — إعداد متصفح Chrome بوضع stealth.
* `fetch_images.py` — تحميل الصور وحفظها محليًا.
* `images_to_pdf.py` — تحويل الصور إلى ملفات PDF.
